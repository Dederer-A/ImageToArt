# Purpose

This project exists to help artists study and understand reference images before drawing or painting.

The application is designed specifically for image analysis, not for image editing.

Its purpose is to simplify observation of proportions, values, composition, shapes and edges while keeping the workflow simple, fast and distraction-free.

---

# Problem Statement

Today, artists often use professional photo editors such as Photoshop, Affinity Photo or GIMP to prepare reference images.

These applications contain hundreds of features that are unnecessary for artistic reference analysis and increase both complexity and learning time.

There is currently no lightweight application focused exclusively on helping artists understand reference images.

---

# Target Audience

This application is intended for:

* traditional artists;
* digital artists;
* art students;
* art teachers;
* hobby artists;
* anyone studying drawing or painting from reference images.

---

# Mission

Create the simplest, fastest and most intuitive cross-platform application for reference image analysis.

The application should help artists spend less time preparing images and more time drawing.

---

# Long-Term Vision

Become the preferred reference analysis tool for artists across desktop and mobile platforms while remaining lightweight, privacy-friendly and easy to learn.

Growth should come from improving analysis capabilities rather than expanding into unrelated functionality.

---

# Non-Goals

This project is not intended to become:

* a photo editor;
* a Photoshop replacement;
* a RAW processing application;
* a digital painting application;
* an illustration tool;
* an AI image generator;
* an AI image editing application;
* a general-purpose graphics editor.

Features that do not directly improve reference image analysis should normally not be implemented.

---

# Success Criteria

The project is successful when an artist can:

* load any reference image;
* analyze it using multiple analysis tools;
* compare different analysis techniques;
* export the resulting image if needed;

without requiring any additional software.

---

# Guiding Question

Whenever there is uncertainty about implementing a new feature, always ask:

> **Does this feature help artists better understand a reference image before drawing?**

If the answer is **No**, the feature probably does not belong in this project.
